# descriptive_stats
** Based on work for my master's thesis **

This code takes raw data from other functions. The code compares the change in the number of olive fruit flies in all traps in a region when a spraying event occurs (i.e., when some spraying happens in a region). 
For all traps in the region, the number of olive fruit flies in the trap 20 days before spraying, and 20 days after spraying is counted, around any spraying in a region. The difference between these two values is calculated. 

The results of this comparison is then grouped by region, and by whether the traps themselves were sprayed (i.e., within the buffer of the spraying tracks) or unsprayed (not within the buffer). This is then the basis of some simple descriptive statistics.
